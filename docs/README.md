# 文档索引

## 1. 范围与格式约定

本仓库采纳 `~/.pi/agent/guides/markdown-doc-format-spec.md` 的默认约定，适用范围为 `docs/` 下子目录。

强制条款：

- front matter 四项齐备：`title` / `type` / `status` / `updated`
- `title` 与 `# 标题` 一致
- 相对链接可解析

本地差异：无

根目录 `README.md`、`AGENTS.md`、`ROADMAP.md` 不在本索引强制范围内。任务进度以根目录 [ROADMAP.md](../ROADMAP.md) 为准。
